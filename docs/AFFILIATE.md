# Cursor アフィリエイト / 紹介

確認日: 2026-08-14

## 結論

**公開の Cursor アフィリエイトプログラムはない。** 紹介プログラムも公式に終了している。

一次情報: https://cursor.com/help/account-and-billing/referral-program

- 新規の紹介リンク・紹介報酬は出ない（終了理由: fraud）
- 既に付与されたクレジットは残る
- いま使える公式の割引は **年払い（月額比 約20%）** と、学生向けチャネルの案内

第三者サイトの「Cursor affiliate 20%」は未確認・公式と矛盾する。このアプリに追跡用の偽パラメータは付けない。

## このアプリの対応

- アプリ内から公式 [Pricing](https://cursor.com/pricing) と [年払いの説明](https://cursor.com/help/account-and-billing/referral-program) へ飛ばす
- 「紹介で稼ぐ」UI は置かない
- Cursor がプログラムを再開したら、公式 URL だけを足す（ダッシュボードの自分のリンクを読む場合も、ユーザー本人の紹介に限る）

## 販売（Usageboard 側）

Cursor の契約を売っているわけではない。売っているのは **このウィジェットの Windows インストール**。

| 経路 | 価格 | 対象 |
|------|------|------|
| GitHub ソース (MIT) | 無料 | 自分でビルドする人 |
| GitHub Release の exe | コミュニティ配布 | ソースから作ったもの |
| Microsoft Store | 買い切り ¥980 / $6.99 | サポート付きインストール |

Cursor 本体の課金はすべて cursor.com。
