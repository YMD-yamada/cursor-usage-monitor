# Persona — Usageboard

## Who it is for

毎日 **Windows 上の Cursor** でコードを書く人。自分の Pro / Pro+ / Ultra を使い、セッション中に Usage を見たい。

典型:

- ダッシュボードを開くたびに作業が切れるのが嫌
- Cursor Models と Other Models の2本を、公式と同じ見方で常時置きたい
- 従量が知らないうちに ON のまま課金されるのが怖い
- プラン変更や Spending の操作は公式ページでよい。見えて、飛べればいい

## Who it is not for

- Cursor を使っていない人
- 他人の Usage を見たい人
- Cursor 公式ダッシュボードの代替が欲しい人（これは非公式ウィジェット）
- チーム管理者向けのシート一括管理

## Promise

「自分の Cursor セッションの Usage を、公式と同じ2プールで常駐表示する。従量とプランの操作は公式へ。」

## Voice

短く、公式の言葉を使う（Cursor Models / Other Models / 従量 / Spending / Billing）。誇張しない。「公式」「提携」とは言わない。
